# AI Hotel Booking System

## Жобаның мақсаты

AI көмегімен қонақүй бөлмелерін броньдау процесін автоматтандыру және дербестендіру.

## Негізгі мүмкіндіктер

- Қонақүй бөлмесін броньдау
- AI арқылы бөлме ұсыну
- Төлемді растау
- Бөлме мәртебесін бақылау
- Статистика және есептер
